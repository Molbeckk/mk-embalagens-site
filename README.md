# MK Embalagens — site (rascunho)

Modelo de site para a MK Embalagens, fábrica de sacolas e bobinas plásticas.

**Status: RASCUNHO.** As páginas estão com `noindex,nofollow` e há um `robots.txt`
bloqueando indexação. Há marcadores `⟦FALTA⟧` e `⟦CONFIRMAR⟧` no conteúdo, que
correspondem a dados que ainda precisam ser confirmados pela empresa.

- `index.html` — home
- `guia.html` — guia técnico (micragem, medidas, normas)
- `tokens.css` — variáveis de cor e tipografia (referência)

Arquivos estáticos, sem build. Para rodar local: abrir `index.html` no navegador.
